# ITSupport

Sistem IT Support - Inventory Barang, Penerimaan, dan Serah Terima

## Setup

1. Copy `application/config/database.example.php` ke `application/config/database.php`
2. Isi credentials database di `database.php`
3. Jalankan aplikasi di web server (Apache/Nginx) dengan PHP

## Tech Stack

- PHP 7+ / CodeIgniter 3
- SQL Server / MySQL
- Tailwind CSS
- jQuery + Select2
