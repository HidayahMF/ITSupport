## How to add screenshots

1. Capture the screen in a clean state (no sensitive employee data; blur NIPs/names if needed).
2. Save the file into this folder, e.g. `docs/images/dashboard.png`.
3. Reference it from the root `README.md` inside the "Screenshots" section:

```markdown
## Screenshots

![Dashboard](docs/images/dashboard.png)
```

Do not fabricate screenshots — only add real captures of the running application.
